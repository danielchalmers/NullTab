# Null Tab

A blank new tab page for focus and speed. Minimal, distraction-free, and theme-aware.

## Why

Most new tab pages are heavy. Null Tab renders nothing but a background that follows your browser theme, helping you stay focused and keeping your machine fast.

## Features

- Blank new tab page (no widgets, no feeds, no noise)
- Theme-aware background color
- Zero permissions, zero scripts
- Lightweight and fast

## Install (development)

Chromium (Chrome, Edge, Brave, Opera):

1. Open `chrome://extensions`.
2. Enable **Developer mode**.
3. Click **Load unpacked** and select this folder.

Firefox (MV3):

1. Open `about:debugging#/runtime/this-firefox`.
2. Click **Load Temporary Add-on**.
3. Select `manifest.json` in this folder.

Safari (WebExtensions):

Use Apple's WebExtensions tooling to package the extension for Safari.

## Build

Nothing to build. The extension is static.
