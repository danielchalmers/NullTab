# Null Tab

[![Chrome Web Store version](https://img.shields.io/chrome-web-store/v/fliommnhefkkgndapepdijobdkgopimb?label=Chrome%20Web%20Store)](https://chromewebstore.google.com/detail/fliommnhefkkgndapepdijobdkgopimb)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

Null Tab is a free, open-source extension for Chrome and Microsoft Edge that replaces the new tab page with a blank page.

**[Add it from the Chrome Web Store](https://chromewebstore.google.com/detail/fliommnhefkkgndapepdijobdkgopimb)** (the same link works in Edge)

- No widgets, no feeds, no noise.
- The background follows your light or dark theme.
- Zero permissions and zero scripts. The whole extension is one HTML file and one CSS file.
- Nothing is collected or sent anywhere ([privacy policy](PRIVACY_POLICY.md)).

## Chrome's footer

Chrome shows a footer with the extension's name on any new tab page that comes from an extension. To hide it, right-click the footer and choose **Hide footer on new tab page**, or turn off **Show footer on new tab page** in Customize Chrome. Edge has no footer.
